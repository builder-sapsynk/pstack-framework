# Worker capability map

- [Native tools](tools.md) verifies actual read, edit and approved checks.
- [Confinement](confinement.md) verifies the observed host boundary and reports isolation limits.
- [Lifecycle](lifecycle.md) verifies durable status, logs, checkpoint and local cancellation.
- [Persistent follow-up](persistence.md) verifies a completed session resumes with context.

A successful tools drive does not imply every other feature has passed.
