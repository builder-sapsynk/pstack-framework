# Claude Code host adapter

The same pstack skills and portable role policy apply when Claude Code becomes coordinator. Its native Agent/Task, Todo, user-question, permission and background-task tools replace Codex-specific mechanisms according to the installed schema. Load full personas through supported agent definitions or explicit child instructions. Shared policy stays in the same project configuration; a small CLAUDE.md entry points at it.

Claude Code can run native Claude roles and use the terminal runner for external Codex or Grok roles. It must not reroute based on inherited parent environment markers. The parent resolves transport explicitly. External runner evidence and workspace ownership contracts stay the same. Claude session hooks and loops are enabled only through supported installation and trust mechanisms.

Native Claude coordination has not been live-tested by installing this Codex distribution. Executable external Claude Code support and native host support are separate capabilities. Verify native invocation, role effort, fresh-session loading, permission enforcement, background lifecycle and recovery on the target host before promoting that host adapter.
