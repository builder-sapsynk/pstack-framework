# Model routing feature map

| Feature | User path | Proof |
| --- | --- | --- |
| [Doctor](doctor.md) | Discover host/provider readiness before setup. | Actual JSON provider statuses and native capabilities retained. |
| [Availability smoke](smoke.md) | Run one bounded task per option and check its artifact. | Authentic terminal receipt, model identity, independent artifact checks and availability-only summary. |
| [Repeated selection](selection.md) | Compare balanced options before applying role bindings. | Fair repeated task matrix, rubric, measured/unknown cost labels, variation and defensible selected/inconclusive verdict. |

Cover each applicable entry point when its behavior changes. Extend the map through the packaged maintain-verification-skill as verified native hosts and harnesses arrive. Fake executable fixtures prove parser behavior only.
