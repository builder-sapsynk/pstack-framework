# Sapsynk pstack

Read `../../adapters/CONTRACT.md` and the active host adapter before work. Read the project's framework lock and configuration. Load `../poteto-mode/SKILL.md` in full, select its matching playbook, and apply its required leaf skills from this installed distribution. Preserve the selected playbook's steps and explicitly record unmet requirements.

Use this framework as the main router for substantive project work. Casual turns and mechanical changes need only the relevant narrow guidance. Other plugins provide specialist capabilities; do not route to another plugin's reduced pstack skill because its name matches.

Use `../provider-agent/SKILL.md` to call authenticated Claude Code or Grok Build agents through terminal tools. Use native children for supported host-native models. Judge actual receipts/artifacts; failed or unavailable providers never count as agreeing reviewers.

Project and global bootstrap establish persistent entry instructions. A release pin survives new chats through committed project configuration. Never silently upgrade it during a build. Preserve configured commit identity. A new VM must run the pinned bootstrap before using the framework.
