# Grok Build adapter

Grok Build runs directly as an external CLI worker through [the runtime](../runtime/README.md). It is not a native Codex model slug. The [managed-host adapter](grok-native.md) qualifies native read/search/edit tools, exact approved commands, durable jobs and resumable sessions. This is the preferred routine lane on the tested Codex cloud. The runtime checks the actual outer host boundary before inference; Grok's inner bwrap/Landlock confinement is unavailable here. Shared host restrictions do not imply per-worker credential, process or VM isolation.

The response-only alternative uses exactly `{"id":"grok-build-1","confinement":"response-only"}` with `mode: "read-only"`. It excludes model tools, returns an artifact and requires the coordinator to apply changes and checks. It refuses isolated writing and command grants. Never silently fall back between capability profiles.

The response-only and restricted native profiles confirm supported help, authenticated model catalog and clean native discovery. Unexpected hooks, MCP servers, project instructions or plugins block execution. Compatibility scanners and memory stay disabled. Those two profiles also disable nested delegation and web. The opt-in full task profile is separate; read the managed-host adapter before using `grok-build-native-task-1`. Exact served-model/session/result checks are independent of billing labels. Effort is pinned argv evidence unless native execution reports more. Bundled skills may remain observed; their presence is not activation proof.

Use `verify-agent-parity` for native tools and lifecycle qualification, `verify-model-routing` for availability or repeated quality/latency/cost selection, and the project's verifier for actual changes. Live native read/edit/check, two owned simultaneous writers, chained session follow-ups and local cancellation were exercised on unrelated synthetic fixtures. A real framework verifier also passed through native Grok commands, although that broader review request exceeded its deadline and does not count as a completed reviewer vote. These observations do not certify native Codex API, coordinator, separate-VM or remote API cancellation parity.

When Grok is the coordinator, discover its actual collaboration, permission and lifecycle controls and map them through the portable contract. Preserve upstream pins, roles, aliases, panel counts and judging order. Doctor is preflight, not live execution. Quota hits are temporary health events; they do not disable an enabled model or rewrite its binding. No implicit provider fallback is permitted.
